# HimitsuX: Anime & Manga Client for Android and Android TV

**Himitsu (秘密; Him-itsu)** means "secret" in Japanese. *Shhh.*

**HimitsuX** is a modernised anime & manga client — browse, track, watch and read with AniList integration, extension repositories you choose yourself, downloads, and a full Android TV (leanback) experience.

> **HimitsuX is developed and maintained by [Nekosphere](https://github.com/Nekomo-App) — founded, developed, and led by [N3K0](https://github.com/MarshMeadow).**

> [!IMPORTANT]
> **HimitsuX is a client only.** It ships with **no sources, extensions or content**. Title metadata comes from AniList and other third-party APIs; everything playable or readable comes from extension repositories *you* choose to install.

## Features

- 📺 **Anime & manga in one app** — browse, search, track and play or read
- 🧩 **Extension repositories** — Aniyomi anime + Mihon manga extensions (`index.min.json` / `index.pb`); nothing bundled
- ▶️ **Playback** — Media3/ExoPlayer with HLS, subtitles, server & quality selection, seek and resume
- ⬇️ **Downloads** — offline episodes via the optional download add-on
- 🎮 **Android TV** — leanback layout, D-pad navigation and TV playback controls
- 🔐 **AniList account** — sign in for library sync, or use guest mode
- 🌓 **Themes & layout** — Material You, OLED mode, dense poster-grid library view
- 🔄 **In-app updates** — checks GitHub releases for new builds
