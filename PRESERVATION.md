# Preservation note

This repository is a **source archive of Himitsu** (`ani.himitsu` / `ani.himitsu.matagi`),
the open-source Android anime/manga client forked from Dantotsu.

## Provenance

- Original project: `github.com/RepoDevil/Himitsu` (deleted; README also pointed at
  `gitlab.com/RepoDevil/himitsu`, also gone). 187 stars at time of deletion.
- This copy: cloned from `gitlab.com/luciobortoletto/himitsu-italian-translation`,
  a Crowdin translation fork carrying the complete app source.
- Snapshot commit: `5b18e04` ("Change Italian translation", 2024-09-03), branch `himitsu`.
- Store listing (Appteka): version `1.0.1-matagi`, package `ani.himitsu.matagi` —
  matches `applicationId "ani.himitsu"` + `.matagi` suffix in `app/build.gradle`.

## Caveats

- Commits made to the original repo **after 2024-09-03 are not included**
  (the listed release is Dec 2024).
- Upstream (pre-fork): `rebelonion/Dantotsu`.
